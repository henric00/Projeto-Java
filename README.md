# Projeto-Java

Descrição
- Simulador de batalhas por turnos entre equipes (Luz vs Trevas) com personagens (`Soldado`, `Berserker`, `Arcanista`, `Cacador`, `Assassino`, `GuardiaoDeFerro`).
O jogo consiste em um duelo entre duas equipes (Luz e Trevas). Eu utilizei a biblioteca Swing para criar uma interface visual onde o usuário pode montar seu time e acompanhar o log de combate em tempo real.
O que eu usei de POO:
Herança e Polimorfismo- Foi cirado uma classe base Soldado e várias subclasses que atacam de formas diferentes.
Encapsulamento- Todos os atributos dos soldados são protegidos, garantindo que a vida e o nível só mudem pelas regras que eu defini.
- Interface gráfica em Swing com criação de equipes, painel de batalha, barras de vida e log de eventos.
# Pré-requisitos
- Java JDK 21 ou superior

# Executar o programa (abre a tela de criação)
Abra o arquivo Main.java no editor.
